### Xie (2026). *The Intruder Threshold: A Spectral Law for LoRA Fine-Tuning.* — HIGH

**Authors / venue / date:** Peng Xie (lead author). arXiv preprint, 27 July 2026.
**arXiv / DOI:** [arXiv:2607.23711](https://arxiv.org/abs/2607.23711)
**One-sentence summary:** Derives a parameter-free per-layer critical update strength from the pretrained weight spectrum via the spiked-deformation transform, validated across seven architecture families (18 adapters, 9,840 layer scans) with AUC 0.89.
**Connection to program:** The spiked-deformation / BBP-transition machinery is precisely the tool that replaces Davis–Kahan for the program's most precisely defined open problem — the concentration-weighted convergence bound. The secular equation gives post-update singular vector overlap as a closed-form root condition parameterized by spectral mass concentration in W₀'s top-k subspace, which is exactly the quantity the program wants to bound by. The per-layer threshold agreement across seeds (ρ = 0.88–0.93) is also independent evidence bearing on the Spectrum Universality open question. Pre-registered, multi-architecture validation is a methodological template the program should emulate.
**Why this criticality tier:** HIGH, not CRITICAL. The merge line is negatively settled and this paper's target quantity (intruder-dimension onset for a single adapter vs. base) is not pairwise adapter alignment, so the machinery would need adaptation rather than direct citation. However, this is the strongest theoretical lead for the convergence bound since the program opened that question — if the program ever revisits formal spectral theory (option (a) substrate generalization), this is the starting point. Also relevant to rank policy validation: the spike-budget rule (62% forgetting reduction at no task cost) is a competing approach to per-layer rank allocation.
**Recommended action:** Add to `RESEARCH_INVENTORY.md` Section 4 at **HIGH**. Flag as primary reference if the program revisits the convergence bound or per-layer rank policy work. No immediate manuscript implications for N134 or N135.
**Framework-applied note:** Pre-registered study with multi-architecture validation across 7 families — meets the program's own measurement-discipline standards for empirical claims. The "factor of two" localization precision and mean AUC 0.89 are reported with appropriate qualification. Worth noting: they do not report cross-seed reliability coefficients (ICC) for the threshold estimate, which the program's framework would require before treating the threshold as a stable instrument.

**arXiv / DOI:** [arXiv:2606.11262](https://arxiv.org/abs/2606.11262)
**One-sentence summary:** Tests whether geometry-aware (Riemannian/Fréchet-mean) merging outperforms plain averaging on Llama-3.1-8B and Mistral-7B with DoRA adapters; finds no consistent advantage and concludes angular alignment/orthogonality are weak predictors of composition performance at decoder scale.
**Connection to program:** Independent corroboration of the Mistral-7B clean null from N134. Second lab, different method family (DoRA/Fréchet-mean rather than principal-angle triage), same two model families, same conclusion — weight-space angular geometry does not predict decoder-scale composition outcomes. Their explicit "shared nonlinear representations" framing converges with the program's option (b) activation-based route.
**Why this criticality tier:** HIGH for N134 specifically. A reviewer encountering both papers will expect N134 to cite this as independent replication evidence that the decoder-scale null is a real property of the substrate, not an artifact of N134's specific instrument. Strengthens N134's published null by showing it is not method-specific. Not CRITICAL because N134 is submission-imminent and the null is already the paper's empirical contribution — PermDoRA supports rather than threatens the claim. For N135, no direct relevance.
**Recommended action:** Add to `RESEARCH_INVENTORY.md` Section 2 (N134 active citation list) at **HIGH**. Cite in N134's §6 discussion as independent replication at camera-ready or first revision. The convergent "nonlinear representations" conclusion is ammunition for the framework paper's option (b) forward direction.
**Framework-applied note:** The paper compares Euclidean vs. Riemannian merging but reports only aggregate performance metrics without cross-seed reliability analysis or effect-size confidence intervals for the null. The program's framework would note this as a precision gap — the null claim is directional ("no consistent advantage") rather than bounded ("the advantage is < X with 95% CI"). Still informative as a convergent finding.

### Cacioli (2026). *Beyond the Mean: Within-Model Reliable Change Detection for LLM Evaluation.* — MEDIUM

**Authors / venue / date:** Jon-Paul Cacioli (single author). arXiv preprint, 30 April 2026.
**arXiv / DOI:** [arXiv:2604.27405](https://arxiv.org/abs/2604.27405)
**One-sentence summary:** Adapts the Reliable Change Index (Jacobson & Truax 1991) from clinical psychology to item-level LLM version comparison; finds most items show no reliable change between model versions while aggregate scores suggest improvement.
**Connection to program:** N134's psychometric toolkit includes minimal detectable change (MDC); RCI is the same statistic family. This paper already operationalizes it for LLM evals with a clean empirical demonstration, including a published near-null ("most items show no reliable change") — structurally the same publication move as N134's pre-registered spectral triage null.
**Why this criticality tier:** MEDIUM, not HIGH. N134 is submission-imminent and the MDC component is one piece of a broader framework, not the headline contribution. The paper does not do reliability coefficients, construct validity, pre-registration, or tolerance schedules — N134's framework claim survives intact. However, N134 can no longer present MDC-for-ML as entirely novel infrastructure; it should cite this at camera-ready and claim the broader framework (pre-registered decision rules + tolerance schedules) as the delta.
**Recommended action:** Add to `RESEARCH_INVENTORY.md` Section 4 at **MEDIUM** with note for N134 camera-ready citation. The aggregate-hides-churn finding is supporting evidence for N134's thesis, not a competitor.
**Framework-applied note:** Single-author study on 2,000 MMLU-Pro items with K=10 samples. The RCI application is methodologically sound within its scope. No cross-benchmark or cross-model-family generalizability analysis — the program's framework would note this as a single-occasion demonstration without reliability-of-the-instrument evidence.
