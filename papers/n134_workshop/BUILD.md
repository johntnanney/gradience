# LaTeX Build

## Current draft

`draft_v2_thesis_b.tex` is the complete first-pass Thesis B draft (approximately 4,500 prose words + appendices + three figures, targeting the 8–10 page range from `draft_v2_thesis_b_outline.md`). Expected to go through at least one revision cycle; see `revision_notes.md` for the revision log.

## Compile

```sh
cd papers/n134_workshop/
pdflatex -interaction=nonstopmode draft_v2_thesis_b
bibtex draft_v2_thesis_b
pdflatex -interaction=nonstopmode draft_v2_thesis_b
pdflatex -interaction=nonstopmode draft_v2_thesis_b
```

Three LaTeX passes are required for the bibliography and cross-references to resolve fully. Intermediate `.aux`, `.log`, `.bbl`, `.blg`, `.out`, `.toc` files are in `.gitignore` and should not be committed.

Output: `draft_v2_thesis_b.pdf` in the paper directory.

## Dependencies

Standard TeX Live (or equivalent) distribution. Specifically required packages:

- `geometry`, `amsmath`, `amssymb`, `graphicx`, `booktabs`, `caption`
- `natbib` (using `plainnat` bibliography style for now; venue-specific style substitutes during submission)
- `microtype`, `hyperref`
- `inputenc` + `fontenc` for UTF-8 text

All of the above ship with a full TeX Live install.

## Figure resolution

## Venue-specific template swap

The current draft uses `\documentclass[11pt]{article}` with 1-inch margins. When the submission venue is locked (candidates: ICML Position Paper track, NeurIPS Reproducibility workshop, NeurIPS Datasets & Benchmarks, ICLR blog post track), the document class and geometry should swap to match the venue's template. The body text and figures should carry over with minimal modification; the primary changes will be:

- Document class and margin/column settings.
- Bibliography style (many ML venues require a specific `.bst`).
- Header/footer and title-page conventions.
- Author / affiliation blocks de-anonymized per venue policy.

## Anonymization

All self-citations use the `anonymized2026n*` bib keys (see `references.bib`). These resolve to "Anonymized" author strings. For de-anonymized versions (e.g., for project archives rather than venue submission), swap the `author` field in each `anonymized2026*` entry to the canonical author list and remove the `note` field. Keeping the bib keys unchanged means the citation commands in the `.tex` do not need to be edited.
