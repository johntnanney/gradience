# n124 — Over-Accumulation Concept Note

Over-accumulation is treated as an additive merge-audit watch condition:

- It does not replace the existing verdict tree.
- It distinguishes "aligned and compatible" from "aligned and potentially inflation-prone."
- It uses existing metrics only (overlap, agreement, rank concentration proxies, assumed coefficients).

Phase-1 output contract:

- layer: score / band / factors
- pair: none|watch|elevated advisory with counts

Interpretation stance:

- diagnostic estimate, not empirical proof
- cautious wording
- validation required before any stronger execution claims
