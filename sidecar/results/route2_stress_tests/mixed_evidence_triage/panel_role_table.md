# Mixed-Evidence Panel Roles

| role_in_panel | count | description |
|---|---:|---|
| anchor_retained | 1 | Clear retained/evaluate-first anchor for upper-bound calibration. |
| anchor_blocked | 2 | Clear blocked weak/QA-override anchors for lower-bound calibration. |
| review | 2 | Mixed-evidence review cases used to probe soft-middle gradation. |
| same_family_optional | 3 | Same-family optional cases (clear and mixed regimes) to test review-likeness stability. |
| other_middle | 0 | Reserved role not used in this panel. |

## Design note

The panel is intentionally skewed toward the soft middle (`review` + `same_family_optional` = 5/8 cases).
