# Getting Started

This section walks you through installing Gradience, running your first audit, and integrating with HuggingFace Trainer.

## Overview

Gradience provides three main interfaces:

1. **CLI** — `gradience audit`, `gradience merge-audit`, `gradience monitor`, etc.
2. **Python API** — `gradience.api` module for programmatic access
3. **HuggingFace Callback** — Drop-in `GradienceCallback` for Trainer
